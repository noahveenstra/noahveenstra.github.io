# Wedding website screenshots

Captured and supplied by Noah on October 27, 2026.

`originals/` contains all ten complete, unmodified PNG uploads at their original resolution. `manifest.json` maps each source filename to its descriptive filename, dimensions, and SHA-256 checksum.

The case study displays the original PNG files directly, using CSS viewports to focus on relevant content and exclude the bottom “Edit site” overlay from the desktop homepage, mobile homepage, and mobile RSVP. No original pixels or files are overwritten. Other editing controls remain visible where they demonstrate the editor.

The RSVP screenshots show a test of an existing household response, including the review step. They do not show a successful final submission and must not be captioned as a confirmation screen.
